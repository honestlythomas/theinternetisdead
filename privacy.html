Privacy

A plain-English privacy note for theinternetisdead.org.

+--------------------------------------------------+ | THE INTERNET IS DEAD. YOUR BROWSER REMEMBERS. | +--------------------------------------------------+

The short version:

This site does not use visitor accounts, logins, or private user profiles.

Most saved site state lives in your own browser through localStorage, sessionStorage, IndexedDB, Cache Storage, or ordinary browser permissions. Some live features use server-side services: public chat uses Supabase, and the Ghosts Online counter uses a WebSocket presence endpoint.

What This Site Stores In Your Browser

This site may store small pieces of information in your browser so the site can remember what you were doing. Revolutionary stuff, apparently.

That may include things like:

  • settings and interface preferences
  • theme or visual customization choices
  • game state, stats, or progress
  • nicknames or profile-like labels you choose locally
  • chat/interface preferences for local command systems
  • saved experimental page states
  • file handles, saved images, or generated project data when a tool asks your browser to keep them
  • temporary route state used by the iframe shell, video routes, and navigation
  • cached site files used by the service worker or browser cache
  • other tiny bits needed for the site to function

Browser Storage

This site mostly uses browser-side storage, such as localStorage, sessionStorage, IndexedDB, Cache Storage, and normal browser cache.

localStorage can stick around after you close the browser.

sessionStorage usually disappears when the tab or session ends.

IndexedDB, Cache Storage, and browser permissions may stick around until you clear site data or revoke permissions in your browser.

This data stays in your browser unless you export it, share it, upload it somewhere, or your browser/device does something exciting and terrible with it.

Public Chat

The public chat stores messages through Supabase so they can appear for other visitors in real time. Public chat records may include the message text, chosen nickname, room name, and timestamp.

Chat nicknames are not verified identities. Do not assume a nickname proves who someone is, and do not use public chat for private information.

The chat clear command can remove public chat history only through a server-side Supabase Edge Function. The admin password is checked by Supabase server-side and is not stored in frontend code.

Do not put private or sensitive information in public chat. Public chat messages are meant to be visible to other visitors.

Ghosts Online Counter

The Ghosts Online display opens a WebSocket connection to this site's /api/ghosts-online endpoint so the page can show an approximate number of active visitors.

The counter is meant to display an aggregate count, not names, accounts, or private profiles. Like any server connection, the hosting provider or runtime may process technical connection information such as IP address, user agent, timestamps, and request metadata in normal logs.

Files And Local Tools

Some games, tools, and experiments let you choose local files, folders, images, audio, video, PDFs, settings files, or generated downloads. Those tools are generally browser-side unless a page clearly says otherwise.

If you choose files in your browser, the page may read them locally to preview, edit, animate, analyze, or export them. Some tools may create downloadable files, screenshots, ZIPs, images, audio, or settings JSON files on your device.

Do not load private or sensitive files into experimental tools unless you are comfortable with how your own browser, extensions, and device handle them.

Embeds And External Services

Some pages embed, link to, or fetch content from external services. That may include YouTube, TuneIn, GitHub, Wikipedia, Supabase, image/avatar services, CDNs, and other linked sites.

Those services may receive requests from your browser and may collect data according to their own privacy policies. Once you interact with an embedded video, external link, external frame, or third-party widget, you may be dealing with that service too.

Browser Features

Some interactions may use ordinary browser features such as fullscreen, clipboard copying, file pickers, drag-and-drop, downloads, service workers, and local caching. Your browser may ask permission for some of these features.

This site does not intentionally use geolocation, camera, microphone, payment information, or contact-list access as part of its normal public site behavior.

Server Logs And Hosting

Even static websites involve servers. The site's host, CDN, edge functions, and third-party services may process technical request information such as IP address, URL requested, browser type, referrer, timestamps, and error logs so the site can load, route, and debug itself.

This site does not use that information to create private visitor accounts or sell personal profiles.

What This Site Does Not Intentionally Collect

This site does not intentionally collect account data, passwords, real names, addresses, payment information, or personal profiles on a private server.

This site is a static web art project with a few live features, not a bank, hospital, or identity platform.

Cookies

This site does not intentionally rely on its own cookies for user accounts or tracking.

Third-party embeds, CDNs, APIs, or links may behave differently. This site cannot control what YouTube, GitHub, Supabase, TuneIn, Wikipedia, CDNs, your browser, your extensions, your device, your internet provider, or other external services do.

Clearing Your Data

You can clear this site's saved local data by clearing browser storage/site data for theinternetisdead.org in your browser settings.

Doing that may delete saved settings, game progress, local profiles, visual customizations, cached files, file permissions, and other browser-stored data.

Clearing browser data does not automatically delete public chat messages that were already sent to Supabase. Public chat history can be cleared only through the site's server-side chat administration flow.

Sensitive Information

Do not enter sensitive personal information into public chat or experimental tools on this site.

This site is an art project and personal web experiment. Treat it like a haunted arcade cabinet, not a secure vault.

Changes

This privacy note may change as the site changes. If new features are added, especially anything involving storage, embeds, uploads, or external services, this page should be updated too. Astonishingly, documentation has to follow reality.
